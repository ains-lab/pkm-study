## Representative behavioral walkthroughs

### Scenario A — school NCP is available

The student designs a VPC/public subnet and restricted ACG, receives a team-scoped Linux VM, records redacted network/budget/owner evidence, demonstrates SSH/service behavior, and fully terminates/releases resources. Hermes can use the live systemd path. CTI, Wiki, UA, and graph work continue through the lineage. The midterm and final both have valid individual evidence routes. **PASS.**

### Scenario B — no NCP; only a lab PC or Docker is initially available

Linux/service work moves to a lab VM or WSL2-with-systemd; NCP control-plane reasoning uses the instructor fixture. Docker may assist collector/Wiki/UA work, but Hermes gateway persistence remains `fixture-only`. The fallback rows explicitly lose real provisioning, public connection/cost interaction, and live persistence/scheduler evidence, so the assessment makes no false equivalence claim. **PASS.**

### Scenario C — CTI API, LLM, or UA enrichment is unavailable

The student preserves last-good state, records bounded failure, and switches to a hash-pinned instructor response/LLM/graph fixture. The work still demonstrates provenance, normalization, validation, projection, metrics, and source checking. It cannot claim current API behavior, current model output, fresh enrichment, or new UA generation. **PASS.**

### Scenario D — partial/stale graph or semantic failure

Expected/completed batches, fresh graph/meta times, unique IDs, array types, and dangling endpoints are checked. A mismatch blocks merge/publish and yields nonzero validation. The student preserves last-good evidence and explains re-entry rather than relabeling stale output as success. **PASS.**

### Scenario E — malicious or prompt-like source text

External/raw/LLM/graph strings are treated as data only. The validator has no shell, network, or eval route. Entity-encoded executable content fails closed; a passive instruction comment remains inert and does not become an external action. **PASS.**

### Scenario F — accessibility or absence accommodation

Every asynchronous video has captions and transcripts, and graphs/tables/commands have accessible text alternatives. Absence handling and retention periods defer to university/instructor policy rather than inventing a penalty or period. **PASS.**
