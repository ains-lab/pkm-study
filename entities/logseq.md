# Logseq

## 개요

Logseq는 개인이 통제하는 지식관리와 협업을 지향하는 오픈소스 도구다. Markdown과 Org-mode, PDF 주석, 작업 관리, 플러그인·테마 확장을 지원하며, 로컬 중심의 노트 그래프를 [[ai-personal-knowledge-management]] 흐름에 배치할 수 있다.

## 현재 확인된 기능

- Markdown·Org-mode를 포함한 여러 파일 형식의 노트 관리
- PDF 주석과 작업 관리
- 플러그인 API와 커뮤니티 확장 생태계
- 데스크톱·모바일 접근
- DB 그래프와 실시간 협업을 위한 새 데이터베이스 버전

## 제약

원본이 설명하는 DB 버전은 베타, 새 모바일 앱과 실시간 협업은 알파 상태이며 데이터 손실 가능성이 명시되어 있다. 따라서 중요한 지식베이스에는 자동 백업이나 SQLite 내보내기를 전제로 한 시험 그래프가 적절하다.

## PKM에서의 위치

[[obsidian]]과 마찬가지로 Logseq는 사용자가 직접 탐색하고 편집하는 인터페이스에 가깝다. [[llm-wiki]]처럼 원본에서 canonical 지식을 자동으로 컴파일하는 운영 규칙을 자체적으로 보장하지 않으므로, 도구 선택과 별개로 원본 보존·출처·링크·검증 정책이 필요하다.
